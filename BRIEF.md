# Ringkit site rebuild — brief (Oct 2026)

Rebuild the Ringkit site (ringkit.ai) using these notes.

## Positioning
- Ringkit is business phone infrastructure: Stripe for voice. Developer-first and agent-first, with humans in the loop.
- Pay per minute, no platform fee, no contracts.
- AI triages and routes each call to a bot or to the right tier of human, either the customer's own team or Ringkit's reps. Every call becomes a summary that turns into tasks and proposals.
- Owners / Developers switch at the top of the page. Owners see the briefed-rep story; developers see the API story. Show the `ringkit.lines.create` code in the hero.
- Line against bot-only products: "Bots for the easy calls, people for the ones that matter."

## Brand
- Mint k-fork wordmark on black (branding/v2/wordmark-wavefork-06-k-fork.png); mint wavefork as stand-alone mark and favicon.
- Single accent: mint #6ee7b7. Amber only for "human" status.
- Dark background, monoline icons, monospace labels for code and data panels.

## Pricing
$1/mo number · $0.05/min AI · $0.50/min live rep.

## Pages
- Launch: Home, Pricing (with per-minute calculator), Docs (quickstart + API reference: REST, JS/Python SDKs, webhooks call.completed / call.summarized / call.routed, sandbox numbers), Sign-up & onboarding (paste site URL → get a number → forward calls), Terms, Privacy, Security.
- Right after: How it works, Integrations, Use cases (contractors, parts sellers, agencies), Status.
- Later: Changelog/blog, Compare (vs bot-only, vs answering services), About, "Work as a Ringkit rep".

## Keep from the earlier version
Hero headline "Your phone, answered. By people who know your business."; the rep/code tabs; the call-to-notes summary card; "Humans in the loop, on purpose"; the routing diagram with three outcomes.
